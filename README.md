# API-автотесты для студенческого сервиса "Яндекс.Самокат"

## Описание

Проект содержит API-автотесты для студенческого сервиса "Яндекс.Самокат". Тесты написаны на языке Python с использованием фреймворка pytest и библиотеки requests. Для формирования отчетов используется Allure.

## Протестированные ручки

*   **Создание курьера (`/api/v1/courier`):**
    *   Проверка успешного создания курьера.
    *   Проверка невозможности создания двух курьеров с одинаковыми данными.
    *   Проверка необходимости передачи всех обязательных полей.
    *   Проверка возвращаемого кода ответа и структуры ответа.
*   **Логин курьера (`/api/v1/courier/login`):**
    *   Проверка успешной авторизации курьера.
    *   Проверка необходимости передачи всех обязательных полей для авторизации.
    *   Проверка возвращаемой ошибки при неверном логине или пароле.
    *   Проверка возвращаемой ошибки при авторизации под несуществующим пользователем.
*   **Создание заказа (`/api/v1/orders`):**
    *   Проверка возможности указания одного из цветов (BLACK или GREY).
    *   Проверка возможности указания обоих цветов.
    *   Проверка возможности не указывать цвет.
    *   Проверка наличия поля `track` в теле ответа.
*   **Список заказов (`/api/v1/orders`):**
    *   Проверка возврата списка заказов в теле ответа.
